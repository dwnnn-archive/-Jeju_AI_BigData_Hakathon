# 결과 설명

> 제주 AI·빅데이터 활용 AI Agent 개발 챌린지 제출용 · 팀: **Synerge_Lab팀**
> 표기 규칙: **[실측]** 실제 이력과 비교해 측정한 값 · **[가정]** 자료가 없어 정한 값 · **[시뮬레이션]** 오차를 가정해 돌려 본 값 · **[보도]** 언론 보도 수치

## 1. 한 문장 요약

제주에서 **내일 출력제한이 생길 위험을 미리 알려 주고, 남는 전기를 어디로 얼마나 보낼지 권고하는** 의사결정 지원 Agent입니다. 도청 에너지 담당 부서 행정담당자가 위험을 조기에 인지하고, 대응안을 검토·승인하고, 관계기관에 통보하는 데까지를 돕습니다. 출력제한의 판단과 지시는 KPX의 몫이며 이 서비스는 설비를 제어하지 않습니다.

## 3. 시연 결과 (위험일)

시연 시나리오 "위험일", 대상일 2026-11-18의 결과입니다. 시연 모드의 발전량은 고정값이며 실제 예측이 아닙니다.

| 항목 | 값 |
|---|---|
| 위험 등급 | **위험** (발전량/수요 비율 최대 73%, 경계 40%·위험 45%) |
| 피크 시간 · 잉여전력 | 12:00~13:00 · **230.0 MWh** |
| 배분 용량 (피크 1시간) | BESS 37.7 · VPP 30 · P2X 3.3 · EV 109.0 MWh |
| 흡수 권고 | **180.0 MWh (78.3%)** |
| 잔여 | **50.0 MWh** |
| 수소 환산 | 약 43 kg (13 kg/MWh 가정) |
| 충전 여력 큰 충전소 | 한국마사회 제주본부, 채비 제주 초급속 충전소, 의귀융복합충전스테이션 (설치 규모 기준) |

**읽는 법**: 공개된 제주 설비 규모만으로는 이 위험일의 잉여를 다 받지 못하고 50 MWh가 남습니다. 서비스는 이를 숨기지 않고 **잔여 전력**으로 보여 줍니다. 과거 위험 판정 176일에 같은 용량을 적용하면, 잉여가 배분 용량 안에 들어오는 날은 EV를 고정 40 MWh로 보면 **83.5%**(147일), 충전 이력 기준으로 보면 99.4%(175일), EV를 빼면 67.0%입니다. 배분 용량의 상당 부분을 EV가 차지하므로, EV 가정이 결과를 좌우합니다.

### 통보문 초안 (Claude가 문장 작성, 숫자는 코드가 검증)

실제 호출 결과 예시는 `03-LLM-초안-예시.md`에 있습니다. 위험일의 LLM 초안:

> 2026-11-18 12:00(KST) 기준 위험등급은 CRITICAL이며, 피크 비율 73%가 경고 기준 40%를 넘고 피크 잉여전력은 230.00 MWh로 예상됩니다. BESS 37.70, VPP 30.00, P2X 3.30, EV 108.99 MWh 분산 흡수로 78.26%를 흡수할 수 있을 것으로 보이며, 잔여 50.01 MWh에 대한 추가 대응 검토를 권고합니다.

LLM이 수치를 바꾸거나 빼면 그 문장은 쓰이지 않고 템플릿 초안으로 대체됩니다.

## 5. 검증 방법

- **과거 날짜 vs 실제 출력제한일**: 점검 기간을 학습에서 완전히 제외한 모델로 2023-01-01 ~ 2024-05-30의 494일을 판정하고 KPX 출력제어 이력과 비교했습니다. 하루라도 풍력 또는 태양광 제어가 있으면 출력제한일입니다.
- **배분 용량 기준별 비교**: 저장된 날짜별 결과에 용량 기준만 바꿔 다시 계산했습니다(`scripts/allocation_sensitivity.py`). 이전 합계 170 MWh 기준의 98.9%가 같은 계산으로 재현되어 계산을 확인했습니다.
- **교차검증**: 허브 기온과 기상청 ASOS를 독립 출처로 비교했습니다.
- **자동 테스트**: 백엔드 215개, 화면 20개, 브라우저 종단 7개(당일 점검 흐름 포함). 외부 네트워크를 호출하지 않습니다. 접근성은 자동 검사(axe)에서 검사한 화면 기준 위반 0건이었습니다(전체 WCAG 적합성 인증은 아님).

## 6. 한계 (숨기지 않고 밝힙니다)

1. **날씨는 실측을 예보 자리에 넣어** 점검했습니다. 과거 예보 이력이 없기 때문입니다. 예보 오차를 [시뮬레이션]으로 섞으면 정밀도가 76.7%에서 49~63%로 떨어집니다. 예보 이력이 쌓이면 임계값을 다시 맞춰야 합니다.
2. **당일 점검의 효과(포착 81~83% → 약 93%)는 [시뮬레이션]**이며 실측으로 확인된 상승이 아닙니다.
3. 제주 출력제한 이력은 **2024-06 초에 끝납니다.** 이후 제도 변화의 영향은 확인하지 못했습니다.
4. **충전 이력은 2021-04와 2022-04의 과거 자료**입니다. 이후 전기차가 늘었다면 오늘의 점유율은 더 높고 EV 용량은 더 작을 수 있습니다. 일별 이력에서 이용이 1년 만에 27% 늘었고, 점유율을 2~3배로 키워도 EV 용량은 75~92 MWh, 위험일 흡수율은 63~71%입니다. 이력의 충전소(422~477곳)는 허브 충전소 3,180곳의 일부입니다.
5. **BESS는 실적 기반 하한**이며 계량값이 제주의 어느 ESS까지 포함하는지는 확인하지 못했습니다. **P2X 3.3 MWh는 [보도]** 수치(행원 그린수소 실증단지 3.3 MW)로 공식 통계가 아니고, **VPP 30 MWh는 근거 자료를 찾지 못한 시연 추정**입니다.
6. 허브 일별 기상은 2025-03 말 이후 비어 있어 서비스 입력으로 쓸 수 없고 교차검증에만 썼습니다.
7. 실시간 충전기·ESS 상태는 알 수 없습니다. 이 서비스는 **권고안**이며 설비 상태를 확인한 제어안이 아닙니다. live 결과는 모델과 가용량이 검증되지 않아 승인과 실제 발송이 차단됩니다.
