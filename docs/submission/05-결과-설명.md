## 1. 한 문장 요약

제주에서 **내일 출력제한이 생길 위험을 미리 알려 주고, 남는 전기를 어디로 얼마나 보낼 수 있는지 대응 후보를 제안하는** 의사결정 지원 Agent입니다. 도청 에너지 담당 부서 담당자가 위험을 조기에 인지하고, 대응안을 검토하고, 통보문을 확인해 관계기관에 발송하는 데까지를 보조 도우미로서 돕습니다. 출력제한의 판단과 지시는 KPX의 몫이며 이 서비스는 설비를 제어하지 않습니다.

## 3. 시연 결과 (위험일)

시연 시나리오 "위험일", 대상일 2026-11-18의 결과입니다. 시연 모드의 발전량은 고정값이며 실제 예측이 아닙니다.

| 항목 | 값 |
|---|---|
| 위험 등급 | **위험** (발전량/수요 비율 최대 73%, 경계 40%·위험 45%) |
| 피크 시간 · 잉여전력 | 12:00~13:00 · **230.0 MWh** |
| 배분 용량 (피크 1시간) | EV 109.0 · BESS 37.7 · VPP 3.2 · P2X 3.3 MWh |
| 흡수 제안 | **180.0 MWh (78.3%)** |
| 잔여 | **50.0 MWh** |
| 수소 환산 | 약 43 kg (13 kg/MWh 가정) |
| 충전 여력 큰 충전소 | 한국마사회 제주본부, 채비 제주 초급속 충전소, 의귀융복합충전스테이션 (설치 규모 기준) |

**읽는 법**: 공개된 제주 설비 규모만으로는 이 위험일의 잉여를 다 받지 못하고 76.8 MWh가 남습니다. 서비스는 이를 숨기지 않고 **잔여 전력**으로 보여 줍니다. 과거 위험 판정 176일에 같은 용량을 적용하면, 잉여가 배분 용량 안에 들어오는 날은 EV를 고정 40 MWh로 보면 **72.2%**(127일), 충전 이력 기준으로 보면 97.7%(172일), EV를 빼면 43.2%입니다. 배분 용량의 상당 부분을 EV가 차지하므로, EV 가정이 결과를 좌우합니다.

### 통보문 초안 (Claude가 문장 작성, 숫자는 코드가 검증)

실제 호출 결과 예시는 `03-LLM-초안-예시.md`에 있습니다. 위험일의 LLM 초안:

## 5. 검증 방법

- **과거 날짜 vs 실제 출력제한일**: 점검 기간을 학습에서 완전히 제외한 모델로 2023-01-01 ~ 2024-05-30의 494일을 판정하고 KPX 출력제어 이력과 비교했습니다. 하루라도 풍력 또는 태양광 제어가 있으면 출력제한일입니다.
- **배분 용량 기준별 비교**: 저장된 날짜별 결과에 용량 기준만 바꿔 다시 계산했습니다(`scripts/allocation_sensitivity.py`). 이전 합계 170 MWh 기준의 98.9%가 같은 계산으로 재현되어 계산을 확인했습니다.
- **교차검증**: 허브 기온과 기상청 ASOS를 독립 출처로 비교했습니다.
- **자동 테스트**: 백엔드 243개, 화면 39개, 브라우저 종단 9개(당일 점검·질문 패널 흐름 포함). 외부 네트워크를 호출하지 않습니다. 접근성은 자동 검사(axe)에서 검사한 화면 기준 위반 0건이었습니다(전체 WCAG 적합성 인증은 아님).

## 6. 한계 (숨기지 않고 밝힙니다)

1. **날씨는 실측을 예보 자리에 넣어** 점검했습니다. 과거 예보 이력이 없기 때문입니다. 예보 오차를 [시뮬레이션]으로 섞으면 정밀도가 76.7%에서 49~63%로 떨어집니다. 예보 이력이 쌓이면 임계값을 다시 맞춰야 합니다.
2. **당일 점검의 효과(포착 81~83% → 약 93%)는 [시뮬레이션]**이며 실측으로 확인된 상승이 아닙니다.
3. 제주 출력제한 이력은 **2024-06 초에 끝납니다.** KPX 운영실적 보고서에 따르면 2024-06-01부터 재생E 입찰제가 시작되어, 입찰제 참여 발전기의 출력 감소는 출력제어 실적에 반영되지 않기 때문입니다. 이후 제도 변화의 영향은 확인하지 못했습니다. ([KPX 「2024년 연간 제주지역 전력계통 운영실적」](https://www.kpx.or.kr/board.es?mid=a10102090000&bid=0159&act=view&list_no=74566&tag=&nPage=1))
4. **충전 이력은 2021-04와 2022-04의 과거 자료**입니다. 이후 전기차가 늘었다면 오늘의 점유율은 더 높고 EV 용량은 더 작을 수 있습니다. 일별 이력에서 이용이 1년 만에 27% 늘었고, 점유율을 2~3배로 키워도 EV 용량은 75~92 MWh, 위험일 흡수율은 52~59%입니다. 이력의 충전소(422~477곳)는 허브 충전소 3,180곳의 일부입니다.
5. **충전소 TOP 5에 같은 이름이 반복될 수 있습니다.** 허브 데이터에 같은 이름이 운영사별로 따로 등록된 곳(예: 제주월드컵경기장 3건)이 있고, 중복 등록인지 확인하지 못해 합치지 않았습니다. 이 경우 EV 용량이 부풀려졌을 수 있습니다.
6. **BESS는 실적 기반 하한**이며 계량값이 제주의 어느 ESS까지 포함하는지는 확인하지 못했습니다. **P2X 3.3 MWh는 [보도]** 수치(행원 그린수소 실증단지 3.3 MW)로 공식 통계가 아니고, **VPP 3.2 MWh는 제주 플러스DR 증대 실적(KPX, 실시간 시장 2023-04 월 평균 시간당 증대량의 최댓값) 기반 하한**입니다. 전기차 충전기 참여분이 포함되어 EV 용량과 일부 겹칠 수 있습니다([출처](https://new.kpx.or.kr/boardDownload.es?bid=0088&list_no=75203&seq=1)).
7. 허브 일별 기상은 2025-03 말 이후 비어 있어 서비스 입력으로 쓸 수 없고 교차검증에만 썼습니다.
8. 실시간 충전기·ESS 상태는 알 수 없습니다. 이 서비스의 배분은 **참고용 대응 후보 제안**이며 도청이 배분을 정하는 것이 아니고, 설비 상태를 확인한 제어안도 아닙니다. live 결과는 모델과 가용량이 검증되지 않아 승인과 실제 발송이 차단됩니다.
9. **원래 의도와 달리 출력제한 물량이나 제3연계선 용량을 직접 계산하지는 않습니다.** 이 서비스의 "잉여전력"은 발전량에서 수요의 40%를 뺀 값이고, 시민 사용량은 수요 예측에 이미 포함되어 있습니다. 40%·45% 기준은 과거 출력제한일(2023-01~2024-05)과 맞춰 정한 경험값이며, 연계선의 정격 용량은 공개되어 있으나([보도] 제1·2·3연계선 300·400·200 MW, [산업통상자원부 자료](https://www.motir.go.kr/attach/down/095a2dda9c864e1d90d751f7668a1117/53f4db8095bb881d66d862db4484bcb0)) 시간대별 연계선 수전전력도 KPX가 [공개](https://www.data.go.kr/data/15100403/fileData.do)합니다(2026-01~09, 273일). 이 자료는 출력제한 이력(~2024-05)과 기간이 겹치지 않아 판정 검증에는 쓰지 못했고 위험 판정에도 반영하지 않았습니다. 참고로 [실측] 2026년 자료에서는 제주에서 육지로 내보내는 방향으로 해석되는 음수 값이 2~5월 낮 시간대에 몰려 있었습니다(세 연계선 합계가 음수인 시간이 있던 날의 비율: 3월 52%, 4월 43%, 5월 74%, 7~9월 0%. 부호 규칙은 파일에 명시되지 않아 추정). 화력발전소의 최소 출력 조건은 데이터가 없어 반영하지 못했습니다. 그래서 결과는 출력제한 **가능성**의 조기 인지용이고, 실제 제한 여부와 물량은 KPX가 정합니다.
10. **배분은 전기차(EV) → BESS → VPP → P2X 순서로, 앞 자원이 다 차야 다음으로 넘어갑니다.** EV는 제주데이터허브 충전소·충전 이력으로 용량을 계산한 자원이고 충전소 운영자·이용자에게 충전 시간 이동을 요청하는 것이 기본 대응이라 먼저 씁니다. BESS·VPP·P2X는 EV로 다 담지 못할 때 보태는 확장 후보입니다. 그 순서는 응답 속도와 제어의 확실성을 기준으로 정한 설계 규칙이며 실제 응답 시간 자료로 검증하지 못했습니다.
11. **11월에는 위험 판정이 실제 출력제한보다 많습니다.** 2021~2023년 11월에는 실제 발전량/수요 비율이 기준(0.40) 이상인 날이 해마다 19·19·21일이었지만 출력제한은 1·13·5일에 그쳤습니다(같은 비율에서 3~5월은 대체로 70% 이상 제한이 걸렸습니다). 모델이 비율을 과대 예측한 것이 아니라(2023년 11월 예측이 실제보다 평균 0.02 낮음) 같은 비율에서도 제한 여부가 달라지는 계통 상황(연계선 가동·역송 여력, 화력발전소 최소출력)의 영향으로 보이나, 연계선 자료가 이력과 겹치지 않아 데이터로 확인하지 못한 추정입니다.
12. **향후 데이터 연동(제안)**: 실측 수요 API가 제공되면 수요 모델의 일일 오차 점검과 재학습에 씁니다. 실측은 전일까지의 값이라 오늘·내일 수요를 대신하지 못해 모델 입력은 대체하지 않습니다. 하루 전 수요예측(PSS)을 자동으로 받을 수 있게 되면 모델 입력으로 쓰고, 시간대별 연계선 수전전력은 출력제한 정답이 있는 기간에서 보조 근거가 되는지 먼저 검증합니다.

- **허브 데이터 연계**: 충전소 정보, 충전 이력, 일별 기상 데이터를 허브 API로 받아 EV 용량과 검증에 씁니다. 허브 데이터가 갱신되면 수집 명령(`04-매뉴얼.md` 4절)으로 다시 받아 결과를 새로 계산할 수 있습니다.

- **센터가 얻는 것**: 허브 충전소·충전 이력 데이터가 실제 대응 용량 계산에 쓰이는 활용 사례, 위험일마다 남는 잔여 전력(ESS·수소 확충 논의의 근거), 분석 이력과 데이터 출처 기록입니다.
- **확장 방향**: 충전소 운영자·사업자에게 통보문 연계(플러스DR 안내), 읍면동별 흡수 여력 지도, 충전소별 우선순위, 예보 이력 기반 임계값 재보정, 실시간 충전기·ESS 상태 연동. 운영 투입 전에는 시범 운영으로 운영 환경 검증이 필요합니다.
- **한계**: 외부 서비스(기상청, 허브)에 접속할 수 있어야 live 분석이 가능하고, 접속이 막힌 환경에서는 시연 모드로 동작합니다.
