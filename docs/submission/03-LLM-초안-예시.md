# LLM 통보문 초안 예시

> 실제 호출 결과를 그대로 저장한 예시입니다. 생성 시각 기준 모델: `claude-opus-5-5`. 시연 입력이며 실제 운영 값이 아닙니다.

## 역할 분담

| 구분 | 담당 |
|---|---|
| 위험등급, 잉여전력, 배분량, 흡수율 | 예측 모델과 규칙(코드)이 계산 |
| 통보문 본문 문장 | LLM이 위 수치를 문장으로 옮김 |
| 수치 검증 | 본문의 숫자가 입력과 다르거나 핵심 값이 빠지거나 400자를 넘으면 템플릿으로 대체, 1회 재시도 |
| 하단 안내 문구, 수소 가정 문구 | 코드가 붙임 |
| 발송 | 담당자 승인 후에만 진행 |

LLM에는 분석이 끝난 수치만 보내며 허브 원본 데이터와 충전소 이름은 보내지 않습니다.
키가 없거나 호출이 실패하면 템플릿 초안으로 동작합니다.

## 예시

### 위험일 (CRITICAL)

- 입력: 시연 시나리오 `critical`, 대상일 2026-11-18, 피크 12:00, 발전량/수요 비율 최대 73%
- 배분 용량: BESS 37.7(제주 ESS 계량 실적의 시간당 최대 충전량), VPP 30·P2X 30(시연 추정), EV 109.0(허브 충전소 + 충전 이력 기반)
- 초안 출처 표시: `llm` (LLM 문장이 수치 검증을 통과함)

**템플릿 초안 (LLM 없음)**

```text
[제주 출력제한 대응 권고] 2026-11-18 12:00 KST
위험등급: CRITICAL, 발전량/수요 비율 최대 73%
피크 잉여전력(수요의 40% 초과분): 230.00 MWh
BESS/VPP/P2X/EV 배분(MWh): BESS 37.7 / VPP 30 / P2X 30 / EV 109
흡수율: 89.87%, 잔여: 23.31 MWh
수소 환산: 390.00 kg (13 kg/MWh 가정)
EV 충전 여력이 큰 충전소(설치 규모 기준): 한국마사회 제주본부, 채비 제주 초급속 충전소(완전공용), 의귀융복합충전스테이션
피크 1시간 권고안. EV 용량만 제주데이터허브 충전소 정보 기반이며 나머지 자원 가용량은 시연 추정치입니다. 현장 검증과 담당자 승인이 필요합니다.
```

**LLM 초안 (Claude `claude-opus-5-5`)**

```text
[제주 출력제한 대응 권고] 2026-11-18 12:00 KST
2026-11-18 12:00(KST) 출력제한 위험등급은 CRITICAL로, 피크 비율 73%가 경고 기준 40%를 넘고 피크 잉여전력은 230.00 MWh로 예상됩니다. BESS 37.70 MWh, VPP 30.00 MWh, P2X 30.00 MWh, EV 108.99 MWh 분산 흡수로 89.87%를 흡수할 수 있을 것으로 보이며, 잔여 23.31 MWh에 대한 추가 대응 검토를 권고합니다. P2X 활용 시 수소 환산량은 390.00 kg(13 kg/MWh 가정) 수준으로 추정됩니다.
EV 충전 여력이 큰 충전소(설치 규모 기준): 한국마사회 제주본부, 채비 제주 초급속 충전소(완전공용), 의귀융복합충전스테이션
피크 1시간 권고안. EV 용량만 제주데이터허브 충전소 정보 기반이며 나머지 자원 가용량은 시연 추정치입니다. 현장 검증과 담당자 승인이 필요합니다.
```
