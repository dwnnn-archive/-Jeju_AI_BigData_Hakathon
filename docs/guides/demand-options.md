# 제주 전력 수요 확보 방안 (갱신 2026-11-16)

잉여전력 계산에 쓸 제주 수요를 어떻게 구할지, 그리고 실제 수요를 넣었을 때 위험 규칙이 맞는지를 정리한다. 현재 서비스의 수요는 시연값(전 시간 500 MWh)이다. **확인됨**은 파일·페이지에서 읽거나 직접 계산한 것, **미확인**은 확인하지 못한 것이다.

## 결론

1. **제주 단독 수요 데이터가 있고 확보했다.** 실측은 2007-01-01 ~ 2026-09-30(7,213일, 하루도 빠짐없음), KPX 하루전 예측은 2017-01-01 ~ 2026-11-16. 이전 조사의 "제주 분리 데이터 없음"은 틀렸다.
2. **권장안**: 실측 수요로 **수요 예측 모델을 학습**(기본), KPX 하루전 예측은 **벤치마크**, 과거 평균 프로필은 **폴백**.
3. **현재 위험 규칙(`발전량 − 수요`, 150/200 MWh)은 실제 규모에서 출력제한을 전혀 잡지 못한다. 확인됐다.** 반면 **발전량 ÷ 수요 비율**은 출력제한 시간을 잘 구분한다. 비율 기반 규칙으로 바꾸는 안을 제안한다(팀 결정 필요).

## 검증 결과

### KPX 하루전 수요예측의 정확도 (실측 대비, 연도별)

| 연도 | MAE (MW) | MAPE (%) | 편향 (MW) | 일 최대값 MAE (MW) |
|---|---|---|---|---|
| 2017 | 30.7 | 4.85 | −20.2 | 32.1 |
| 2019 | 33.5 | 5.07 | −22.5 | 31.1 |
| 2021 | 39.5 | 5.90 | −20.4 | 31.9 |
| 2023 | 36.6 | 5.08 | −13.4 | 30.7 |
| 2025 | 36.1 | 4.96 | −13.3 | 36.0 |
| 2026 (1~9월) | 40.5 | 5.46 | −13.7 | 40.2 |

- 매년 MAE 31~40 MW, MAPE 5~6%이고 **항상 과소 예측**(편향 −13~−22 MW)한다. 공식 예측도 크게 정밀하지는 않다. **우리 수요 모델이 이 값(MAE 약 36~40 MW)보다 낫거나 비슷하면 충분하다.**
- 예측을 ±1시간 이동하면 오차가 커져(MAE 40.5 → 47~49) 실측과 예측은 같은 시간 표기다.

### 위험 규칙 재검증 (실측 수요 사용)
**방법**: 2021-01-14 ~ 2024-05-30(출력제어 이력이 있는 구간) 29,571시간. 발전량은 풍력 잠재(KPX + 제어량) + 태양광, 수요는 **실측**. 출력제어 시간은 1,592시간(5.4%, 풍력 또는 태양광이 제어된 시간).

**1) 현재 규칙은 출력제한을 전혀 잡지 못한다.**

| | 결과 |
|---|---|
| 출력제어 시간의 `발전량 − 수요` | 평균 −229, 중앙값 −230, **최대 +15 MWh** |
| 출력제어 시간 중 잉여 > 0 / ≥ 150 (CAUTION) | 0.1% / **0%** |
| 전체 29,571시간 중 잉여 ≥ 150 | **0시간** |

실제 수요를 넣으면 지금 규칙은 항상 NORMAL이다.

**2) 발전량 ÷ 수요 비율 r은 출력제어 시간을 잘 구분한다.**
- 출력제어 시간의 r은 평균 **0.59**(10~90% 0.44~0.76), 나머지 시간은 평균 0.15(99% 0.51).
- 구분력(AUC): 시간 단위 **0.990**, 하루 단위 **0.960**. 발전량만 쓰면 0.973이라 수요로 나누는 쪽이 더 낫다.

| r 임계값(실제 발전량) | 판정 시간 | 출력제어 시간 포착(재현율) | 판정 중 실제 제어(정밀도) |
|---|---|---|---|
| ≥ 0.40 | 2,725 | 94.6% | 55.3% |
| ≥ 0.45 | 2,055 | 87.1% | 67.5% |
| ≥ 0.50 | 1,452 | 72.1% | 79.1% |
| ≥ 0.55 | 1,017 | 55.9% | 87.5% |
| ≥ 0.60 | 703 | 41.9% | 94.9% |

**3) 우리 모델의 예측 발전량으로도 잡히는가** (2023-01 ~ 2024-05, 12,053시간, 제어 792시간. 풍력 모델은 원래 학습 밖, 태양광 모델은 이 구간을 빼고 재학습, 기상은 **실측**)
- 시간 AUC: 실제 발전량 0.990 → 예측 발전량 **0.980**. 하루 AUC: 0.959 → **0.948**. 예측으로도 거의 유지된다.
- 예측 r 기준 하루 단위 판정(평가 507일 중 제어일 168일):

| 예측 r(하루 최대) ≥ t | 위험일 | 제어일 포착 | 정밀도 |
|---|---|---|---|
| 0.35 | 268일 | 96.4% | 60.4% |
| 0.40 | 192일 | 89.3% | 78.1% |
| 0.45 | 148일 | 77.4% | 87.8% |
| 0.50 | 108일 | 59.5% | 92.6% |
| 0.55 | 64일 | 36.9% | 96.9% |

모델이 극값을 낮게 예측해서 예측 r의 임계값은 실제 r보다 약 0.1 낮게 잡아야 같은 수준이 된다.

**4) 수용 한계 추정 — 배분량(MWh)의 근거**
출력제어량 이력(풍력 시간별 MWh)을 정답으로 `초과량 = max(0, 발전량 − k × 수요)`가 맞는지 보았다.

| k | 전체 시간 MAE | 제어 시간 MAE | 초과량 합 / 제어량 합 |
|---|---|---|---|
| 0.50 | 1.67 | 26.1 | 1.28 |
| **0.55** | **1.37** | **24.1** | 0.83 |
| 0.60 | 1.46 | 27.2 | 0.52 |
| 기준선(제어 0 예측) | 2.47 | 46.8 | — |

- k = 0.55에서 시간별 오차가 최소이고, **k ≈ 0.52~0.53에서 초과량의 합이 기록된 제어량의 합과 거의 맞는다.** 제어를 0으로 예측하는 기준선보다 낫다(제어 시간 오차 46.8 → 24.1).
- 해석: **계통은 대략 수요의 절반 남짓(약 52~55%)까지만 재생에너지를 받을 수 있는 것으로 보인다.** 정밀한 값은 아니며, 태양광 제어량은 이력에 없어 실제 제어 총량은 이보다 커서 k는 다소 낮을 수 있다.

## 제안: 위험 규칙 변경 (팀 결정 필요)

지금의 `잉여 = max(0, 발전량 − 수요)`와 150/200 MWh 기준을 아래로 바꾸는 안이다. **이 문서는 제안만 하고 코드는 바꾸지 않았다.**

| 항목 | 현재 | 제안 |
|---|---|---|
| 위험 판단 | 잉여 MWh 기준 150 / 200 | **예측 발전량 ÷ 수요 비율**의 일 최대값 |
| 등급(예시) | NORMAL < 150 ≤ CAUTION < 200 ≤ CRITICAL | NORMAL < 0.40 ≤ CAUTION < 0.50 ≤ CRITICAL (예측 r 기준, 위 3) 표) |
| 흡수해야 할 양 | 발전량 − 수요 | `max(0, 발전량 − 0.55 × 수요)`(수용 한계, 위 4)) |
| 경계 재검증(R4) | 190~200 MWh | 임계값 ±0.03 부근으로 이동 |

- 등급 경계의 의미: 예측 r ≥ 0.40이면 제어일의 89%를 잡고 위험일의 78%가 실제 제어일, ≥ 0.50이면 60%를 잡고 93%가 실제 제어일이다. 놓침과 오경보 중 무엇을 더 아끼는지는 운영 판단이다.
- 이 변경은 `rules.py`, 배분(Tool 5)의 입력, 시연 시나리오의 수치와 UX 문구, 기획서의 "잉여 230 MWh"에 영향을 준다.

## 한계와 주의

- **기상은 실측이다.** 서비스는 예보를 쓰므로 실제 구분력은 더 낮을 수 있다.
- 출력제어 이력은 2024-05-30(풍력)·2024-06-03(태양광)에서 끝난다. **2024-06 이후의 검증은 불가능하다**(입찰제 이후 제어가 이력에 없음).
- 수요 값에 "시장 참여 태양광이 포함"된다는 안내가 있다. 발전량(풍력+태양광)과 맞물리는 정확한 정의는 **미확인**(KPX 문의 필요).
- 출력제어는 기상 외에 계통 상황(연계선 상태, 최소 발전 조건)에 좌우되어 비율만으로 완전히 설명되지 않는다.
- 수요 값은 수정정산으로 사후에 바뀐다. 겹치는 파일의 차이는 작았지만(5 MWh 초과 최대 13시간) 최신 정산 값을 받아 두는 것이 좋다.
- KPX 발전량은 시장 거래분이고 ESS가 섞여 있다.
