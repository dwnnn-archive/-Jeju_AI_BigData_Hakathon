# 제주 전력 수요 확보 방안

잉여전력 계산(`발전량 − 수요`)에 쓸 제주 수요를 어떻게 구할지 정리한다. 현재 수요는 시연값(전 시간 500 MWh)이다. 표시는 지금까지의 문서와 같이 **확인됨**(페이지에서 읽음) / **미확인**이다.

## 결론

1. **제주 단독 수요 데이터가 있다.** 이전 조사에서 "제주 분리 데이터를 찾지 못했다"고 한 것은 틀렸다(전국 합산 데이터셋만 확인했었다). 아래 3종이 확인됐다.
2. **권장안**: 실측 수요로 **제주 수요 예측 모델을 학습**하고(기본), KPX 하루전 수요예측은 **벤치마크와 보정용**으로, 과거 평균 프로필은 **폴백**으로 쓴다.
3. **수요를 실데이터로 바꾸기 전에 위험 규칙부터 재검증해야 한다.** 지금 규칙(`max(0, 발전량 − 수요)`, 기준 150/200 MWh)은 실제 규모에서 거의 항상 NORMAL이 될 가능성이 크다(아래 "위험 규칙 재검증").

## 데이터 사용 시 주의

- **발전단 수요 + 시장 참여 태양광 포함**: 수요 값 안에 태양광 발전량이 더해져 있다는 설명이다. 발전량(풍력+태양광)과 맞춰 쓰려면 이 정의를 KPX에 확인해야 한다. 미확인.
- 단위: 2023-09 이전 kWh, 이후 MWh. 1시간 값이므로 MWh는 그 시간 평균 MW와 같다.
- 시간 표기: 1시~24시(종료 시각 표기로 추정). 발전 데이터와 같이 0~23시로 바꾸는 것이 맞는지 확인이 필요하다(미확인, 발전 파일처럼 겹침 비교로 검증 가능).
- 수정정산으로 값이 사후에 바뀐다. 학습 데이터는 받은 날짜를 기록해 둔다.

## 위험 규칙 재검증 (중요)

현재 규칙은 `잉여 = max(0, 발전량 − 수요)`, 150 / 200 MWh에서 CAUTION / CRITICAL이다. 시연값(수요 500, 낮 발전 700 이상)에 맞춘 기준이다.

실제 규모를 확인한 결과(2017~2024-05, 풍력은 출력제어량을 더한 잠재 발전량):

| 구간 | 풍력+태양광 합계 (MWh) |
|---|---|
| 전체 시간 | 평균 101, 99% 344, 최대 580 |
| **출력제한이 있던 1,567시간** | **평균 319, 중앙값 311, 10~90% 233~414, 최대 580** |
| 낮 9~15시 중 제한이 없던 시간 | 평균 155, 90% 257 |

- 제주 수요는 하루 최소가 500 MW대다(2026-11-16 예측 최소 508, 값 하나). 출력제한이 걸린 시간의 발전량(평균 319)은 이보다 작다.
- 따라서 **실제 수요를 넣으면 출력제한이 실제로 있었던 시간에도 `발전량 − 수요`가 음수가 되어 잉여가 0, 등급이 NORMAL이 될 가능성이 크다.** 추정이며, 수요 파일로 확인해야 한다.
- 실제 출력제어는 재생에너지가 `수요 − 최소 가동 발전·연계선 몫`을 넘을 때 걸리는 것으로 보인다(발전량이 수요의 절반 안팎에서 제어됨). 이 몫은 데이터로 추정할 수 있다.

**검증 방법** (수요 파일을 받으면 바로 가능): 2021-01 ~ 2024-05의 시간별로 `잠재 발전량 − 수요`를 계산해 출력제한이 있던 시간과 없던 시간이 어떻게 갈리는지 본다. 이 이력이 위험 기준을 데이터로 맞출 수 있는 **정답지**다.
- 두 집단이 뚜렷이 갈리면 `잉여 = 발전량 − (수요 − 최소 몫)`처럼 규칙을 고치고 기준(150/200)을 다시 정한다.
- 갈리지 않으면 지금 모델 오차(풍력 최대값 MAE 32, 태양광 40 MWh)로는 등급 판정이 어렵다는 결론이 된다.
