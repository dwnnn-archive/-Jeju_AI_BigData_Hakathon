# 기상청 단기예보 API 적용 지침

출처: 「기상청41_단기예보 조회서비스 오픈API 활용가이드(2610)」 docx와 격자·위경도 xlsx(2026-09-30판). 코드는 `backend/app/providers/kma.py`, 격자 값은 `backend/app/tools/tool1_kma_weather.py`의 `GRID`에 있습니다.

## 호출 규격

| 항목 | 값 |
|---|---|
| 서비스 | `VilageFcstInfoService_2.0`, REST GET, XML/JSON |
| 기본 URL | `https://apihub.kma.go.kr/api/typ02/openApi/VilageFcstInfoService_2.0` |
| 사용 기능 | `getVilageFcst`(단기예보). 그 밖에 `getUltraSrtNcst`(초단기실황), `getUltraSrtFcst`(초단기예보), `getFcstVersion` |
| 필수 파라미터 | 인증키, `base_date`(YYYYMMDD), `base_time`, `nx`, `ny`. `dataType=JSON`, `numOfRows`, `pageNo`는 선택 |
| 한도 | 초당 30건(tps), 단기예보 응답 최대 약 48KB, 평균 600ms |

**인증 파라미터 표기가 가이드 안에서 다릅니다.** 요청 명세표는 `serviceKey`, 예제 URL은 `authKey`입니다. 기본값은 예제 기준 `authKey`이고, 키를 발급받은 곳에 맞춰 `.env`의 `KMA_AUTH_PARAM`(`authKey`/`serviceKey`)과 `KMA_BASE_URL`로 바꿉니다. 키는 디코딩된 값을 넣으면 HTTP 클라이언트가 인코딩합니다.

## 발표 시각

`base_time`은 0200, 0500, 0800, 1100, 1400, 1700, 2000, 2300(하루 8회)입니다. API는 각 시각 **10분 이후**부터 제공하므로 `issue_time()`이 10분 지연을 둡니다.

## 응답 처리 규칙

- 정상은 `resultCode` 0입니다. 표에는 `00`, 예제에는 `0`으로 적혀 있어 정수로 정규화해 비교합니다.
- 오류 코드: 03 데이터 없음, 10 잘못된 파라미터, 20 접근거부, 22 요청 한도 초과, 30 미등록 키, 31 기한 만료, 32 미등록 IP 등.
- `totalCount`만큼 받을 때까지 `pageNo`를 늘려 조회합니다.
- ±900 이상 값은 **Missing**(관측장비 없음·결측)입니다. 본 시스템은 이를 오류로 처리하고 값을 만들어 내지 않습니다.
- 해상은 기온군·강수·습도가 Missing으로 마스킹됩니다. 해상 지점을 직접 조회할 경우 TMP가 없을 수 있습니다.

## 사용 요소

| category | 의미 | 단위 | 비고 |
|---|---|---|---|
| WSD | 풍속 | m/s | 풍력 출력 계산 |
| TMP | 1시간 기온 | ℃ | 태양광 온도 손실 |
| SKY | 하늘상태 | 코드 | 맑음 1, 구름많음 3, 흐림 4. 일사량 **추정**에 사용 |

가이드가 제공하지 않는 것은 실측 일사량입니다. `irradiance_wm2`는 SKY와 시간으로 만든 추정값이며, 학습에는 별도의 관측(ASOS 등)이 필요합니다. SKY의 2는 가이드에 없는 값이라 코드 매핑(`{1,2,3,4}`)을 재검토할 필요가 있습니다.

## 예보 기간 (중요)

발표 후 +1~2일은 1시간 간격 정량값입니다. 연장 구간(글피, 그글피)은 **3시간 간격**이고 강수량·강설·**풍속(WSD)은 정성 코드(1~3)** 로 옵니다. 본 시스템은 24개 시간 구간이 모두 있어야 하므로, 연장 구간만 있는 날짜는 거부됩니다. 시간별 분석은 발표 기준 모레까지 쓰는 것이 안전합니다.

## 격자 좌표 (xlsx 공식값)

| 지역 키 | 행정구역 | nx | ny |
|---|---|---|---|
| jeju | 제주시 | 53 | 38 |
| hallim | 제주시 한림읍 | 48 | 36 |
| jocheon | 제주시 조천읍 | 55 | 39 |
| haengwon | 제주시 구좌읍 | 59 | 38 |

위경도 변환식(람베르트 정각원추)은 가이드의 C 예제와 같은 결과(예: 126.929810, 37.488201 → 59, 125)를 냅니다. 한림해상풍력 같은 **해상 설비의 정확한 격자**는 별도로 정해야 합니다(읍면동 대표점은 육지 기준).

## 미확인 사항

실제 API 키로 호출해 확인한 내용이 아닙니다. 키 승인 후 확인할 것: 인증 파라미터 이름, 응답의 `resultCode` 형태, 키 발급처에 맞는 URL, IP 제한 여부.
